# 🏦 Bank Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Bank Analytics Dashboard** created using **Microsoft Power BI**.

The dashboard is designed to analyze banking/customer data and provide useful insights through KPIs, charts, filters, and interactive visualizations.

## 🎯 Project Objectives

- Analyze overall banking performance
- Understand customer demographics and behavior
- Track account and transaction-related metrics
- Identify important trends and patterns
- Create an interactive dashboard for business reporting
- Present data in an easy-to-understand visual format

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Modeling** – Relationships between tables
- **Excel/CSV** – Source data

## 📊 Dashboard Features

The dashboard includes:

- Total Customers
- Total Accounts / Banking Metrics
- Key financial KPIs
- Customer segmentation
- Age / demographic analysis
- Geographic analysis
- Transaction or financial trend analysis
- Interactive slicers and filters
- Charts and KPI cards for quick business insights

## 🔄 Project Workflow


## 🚀 How to Open the Project

1. Download or clone this repository.
2. Install **Power BI Desktop**.
3. Open `Bank_Final_Dashbaord.pbix`.
4. If Power BI asks for the source data, update the data source path.
5. Refresh the data if required.
6. Explore the dashboard using the available slicers and filters.
